- PWA: service worker generated by vite-plugin-pwa (/sw.js) with push logic in public/push-handler.js via importScripts; registration only through src/lib/pwa.ts, which refuses dev/preview — keeps previews cache-free.
- Web push is sent from server functions using @block65/webcrypto-web-push with VAPID keys in secrets — works on the Worker runtime (no Node crypto).
